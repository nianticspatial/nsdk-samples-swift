# SwiftyNsdk

Welcome to the SwiftyNsdk documentation. This is the high-level Swift API surface for NSDK.

## Overview

- Integrates with the native C layer shipped in `CArdk.xcframework`.
- Provides Swift-friendly types and feature APIs (VPS, Mapping, Meshing, Scanning, Semantics, etc.).
