# NSDK Samples
This Swift project provides examples for many of the Niantic Spatial SDK (NSDK) features.

## __Quick links:__
* [NSDK API Reference](https://www.nianticspatial.com/docs/api/swift/?platform=swift)
* [Documentation](https://www.nianticspatial.com/docs/nsdk/sample_projects/?platform=swift)
* [Niantic Spatial Platform](https://www.nianticspatial.com/docs)

# Getting Started

Clone this repository or download the source code from the Releases tab and open it in Xcode.

Select the sample or scheme for the feature you'd like to reference, then build and run on a device or simulator.
If you find yourself having problems using our samples, please refer to our [documentation page](https://www.nianticspatial.com/docs/nsdk/sample_projects/?platform=swift) for more information.

To build the samples on an iOS device, follow our [Setup Guide](https://www.nianticspatial.com/docs/nsdk/setup/?platform=swift).
